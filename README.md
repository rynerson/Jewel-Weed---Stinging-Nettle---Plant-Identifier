# Jewel-Weed---Stinging-Nettle---Plant-Identifier
WHAT: This project detects the difference between stinging nettle and jewel weed plant images from the INaturalist datasets for common stinging nettle (Urtica Dioica) and orange jewel weed(Impatiens Capensis) plants. 
WHY: This was the final project for my CSC 746: Artificial Intelligence course. We were allowed to design our own projects. I chose to develop a image classifier to detect the difference between stinging nettle and jewel weed because both plants are located where I live. Jewel weed is traditionally known as the remedy for stinging nettle and poison ivy so having a way to differentiate between the two plants would be useful. 
HOW: I used the INaturalist API to retrieve images from both datasets. I used Pytorch for building the CNN. I chose to use a convolutional neural network because they are useful for detecting objects within images. I resized all of the images going into the network and applied transformations on the images so that the model would not memorize irrelevant details like lighting and rotation. I used three convolutional layers and three fully connected layers. The final layer outputs the prediction. I used max-pooling between convolutional layers to reduce the size of the feature maps while retaining the most important details. I used ReLU as the activation function for the model. I trained the model for 20 epochs. For evaluating the model, I used several metrics. The most important metric for my model was precision for the jewel weed class. This is because I wanted to reduce false positives for the jewel weed class. It is far worse to identify a plant as jewel weed when it is actually stinging nettle than identify a plant as stinging nettle when it is really jewel weed. I also collected several other metrics, including recall and f1 score for both classes. I also developed a confusion matrix to visualize the predictions and what category they belonged to (TP, TN, FP, FN). I also collected accuracy for both classes because I wanted to compare the accuracy in training with the accuracy in testing to check for signs of over-fitting. I achieved a precision of 0.93 for the jewel weed class and a precision of 0.85 for stinging nettle. This indicates that the model has fewer false positive cases for jewel weed identification than stinging nettle I also obtained a recall score of 0.87 for jewel weed and a score of 0.92 for stinging nettle. This indicates that the model is better at catching the true positives for stinging nettle than jewel weed. I obtained an f1-score of 0.90 for jewel weed and a score of 0.88 for stinging nettle. F1-score is a metric that balances precision and recall. This result indicates that the model was best at classifying jewel weed overall. The model achieved an accuracy of 89.06% in training and an accuracy of 88.89% in testing. This indicates that the model is getting most of the predictions correct. 
TOOLS USED: Pytorch, Scikit-Learn, Jupyter Notebook, pathlib, requests.
Dependencies: This project requires Python 3.14.6. You will also need Jupyter Notebooks.
How to Run: The code is in the plantClassifier.ipynb file. You can run it from start to finish to reproduce the results. Double check that both the jewelweed and stinging nettle folders have roughly 200 images each. Theoretically, an image could get skipped if it is not research quality grade.
